Programozás & web

A digitális alkotás fejlesztői oldala: algoritmusok, alkalmazások, adatbázisok és webes felületek.

A műhely szerepe

A műhely a programozási gondolkodástól az önállóan futtatható és adatbázissal kommunikáló alkalmazásokon át a weboldalakig és tartalomkezelő rendszerekig vezeti végig a fejlesztési folyamatot.

Python és programozási alapok

  • Blokkprogramozás
  • Adatok és kifejezések
  • Algoritmusok és alprogramok
  • Fájlok, kivételek és objektumok
  • Önállóan futtatható programok
  • Ablakos programok
  • Adatbázis-kapcsolat

Adatbázis-kezelés

Access és Base használata, SQL nyolc leckében, majd SQLite és MySQL.

Webszerkesztés

HTML5, CSS3, Bootstrap, JavaScript CLI és DOM.

Tartalomkezelés

WordPress alapú tartalomkezelés.
